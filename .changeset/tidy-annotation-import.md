Import Georeference Annotations from files, pasted text, and URLs as control points, Allmaps layers, mask polygons, or a combination. Imported features and layers are independent snapshots and can be undone together.

Keep all maps in each imported annotation together in one background layer. Use embedded manifest and canvas labels in the import dialog, layer names, and data folders when available.
